# Power-BI-data-modeling-project
End-to-end Power BI data preparation and dimensional modeling project.

## Project Overview

This project demonstrates an end-to-end data preparation and dimensional modeling workflow using Microsoft Power BI.

The main objective is to transform raw source tables into a structured analytical data model using Power Query and Power BI's semantic modeling capabilities.

## Objectives

- Organize raw data into structured query groups.
- Develop dimension and fact tables.
- Clean and standardize source data.
- Identify and resolve duplicate records.
- Establish relationships using surrogate or business keys as appropriate.
- Develop factless fact tables and accumulating snapshot fact tables.
- Create a reusable date dimension.
- Validate the final data model and aggregation settings.

## Tools & Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX
- Git
- GitHub

## Data Modeling Approach

The project follows these main stages:

1. Data organization and staging.
2. Dimension table development.
3. Junk dimension identification.
4. Fact table development.
5. Factless fact table development.
6. Accumulating snapshot fact table development.
7. Date dimension creation.
8. Final model validation.
